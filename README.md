# Barca Zone

تطبيق عربي لعشاق برشلونة مبني باستخدام Vite وJavaScript وCapacitor، ومهيأ للبناء كتطبيق Android.

## الحالة الحالية

هذه نسخة تأسيسية قابلة للتطوير وليست ادعاءً بأن كل خدمة خارجية متاحة في كل وقت.

- **المباريات والأخبار:** طلبات مباشرة إلى واجهة ESPN Soccer العامة، مع معالجة أخطاء الشبكة وحالات عدم توفر البيانات.
- **الترتيب وقائمة اللاعبين:** تُطلب من مسارات ESPN المحددة؛ التغطية الفعلية قد تختلف، وتُعرض حالة عدم التوفر بدلاً من بيانات مصطنعة.
- **الصور:** تُستخدم روابط المزود عند وجودها، مع بديل محايد عند غياب الشعار أو الصورة.
- **المفضلة والتوقعات والتشكيلة:** تخزين محلي على الجهاز.
- **الوضع الداكن/الفاتح:** قابل للتبديل.
- **واجهة المطور:** روابط التواصل والقناة التي طلبها صاحب المشروع.
- **الاختبارات:** اختبارات تطبيع بيانات منفصلة عن بيانات الإنتاج.

## المتطلبات

- Node.js 20 أو أحدث
- npm
- Java 17 وAndroid SDK عند البناء المحلي
- Android Studio اختياري للتطوير المحلي

## التشغيل محلياً

```bash
npm install
npm test
npm run build
npm run dev
```

## إعداد Android

```bash
npm ci
npm run build
npx cap add android
npx cap sync android
cd android
./gradlew assembleDebug
```

ملف APK المتوقع محلياً:
`android/app/build/outputs/apk/debug/app-debug.apk`

## بناء APK عبر GitHub Actions

يحتوي المشروع على سير عمل في `.github/workflows/build-apk.yml`. بعد رفع المشروع إلى مستودع GitHub جديد، افتح تبويب **Actions** وشغّل **Build Barca Zone APK** أو ادفع commit إلى `main`. سيشغّل السير العمل فحوص الصياغة والاختبارات والبناء ويرفع APK كـ Artifact إذا نجح البناء.

لا يمكن اعتبار APK مبنياً قبل أن ينتهي GitHub Actions بنجاح ويظهر Artifact فعلي.

## مصادر البيانات

- ESPN Soccer: `https://site.api.espn.com/apis/site/v2/sports/soccer/`
- صفحة ESPN Soccer: `https://www.espn.com/soccer/`

تستخدم النسخة الحالية slug الدوري الإسباني `esp.1` ومسارات scoreboard/news/roster المتاحة عبر ESPN. قد لا يوفر ESPN ترتيباً أو قائمة لاعبين في كل مسار/استجابة. لا تُعرض بيانات بديلة مختلقة عند الغياب.

### إضافة API-Football بأمان لاحقاً

API-Football يتطلب مفتاحاً. لا تضع المفتاح داخل JavaScript أو متغيرات Vite التي تُضمّن في التطبيق. أنشئ وسيطاً خلفياً (backend/proxy) يحتفظ بالمفتاح في متغير بيئة خادمي، ثم اجعل التطبيق يتصل بنقاط نهاية الوسيط الآمنة. لا تُفعّل المصدر إلا بعد اختبار التغطية وحدود الخطة فعلياً.

## الخصوصية والأمان

- لا توجد مفاتيح API في المشروع.
- لا ترفع ملفات `.env` أو مفاتيح التوقيع.
- البيانات المحفوظة (المفضلة والتوقعات والتشكيلة) تبقى محلياً في مساحة تخزين التطبيق.
- الروابط الخارجية تفتح في المتصفح.

## المزايا التي تحتاج تطويراً إضافياً

- مزود احتياطي موحد عبر backend آمن.
- إشعارات خلفية حقيقية للأهداف والمباريات؛ تتطلب خدمة خادم وجدولة أو مزوداً يدعم الأحداث.
- أحداث المباراة والتشكيلات الرسمية والإحصائيات التفصيلية، بحسب تغطية API الفعلية.
- اختبار يدوي على جهاز Android فعلي.
- التحقق من مسارات ESPN عبر الشبكة الفعلية وقت التشغيل، إذ يمكن أن تتغير أو تُقيّد.
